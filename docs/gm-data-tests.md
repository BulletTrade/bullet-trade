## 覆盖矩阵

| 接口或契约 | 覆盖 |
| --- | --- |
| `get_price` 全字段 | open/high/low/close、pre_close、high_limit、low_limit、avg、volume、money、factor、paused；联合读取及每个字段单独读取 |
| 复权 | None/none/pre/post；除权前后两参考日；前复权变基准，后复权不随参考日变化；价格乘因子、量除因子、金额保持 |
| 周期 | daily、1m、5m、15m、30m、60m；连续分组与尾部不足一组；分钟金额截断后聚合 |
| 形状与入口 | 单/多证券、宽/长表、字段顺序；标准 history、attribute_history、get_bars 接入 GM；动态回测参考日及缓存已有回归 |
| `get_bars` | count、DF/records、复权参考日；旧验收覆盖 include_now |
| 日历/元信息 | 正反日期、count、重复/乱序/越界拒绝；股票、ETF、MMF、LOF、指数；上市/退市边界 |
| 指数成份 | 假日使用此前交易日；空快照、重复成份拒绝 |
| 分红 | 股票每十股、基金每份；现金、送股、转增、日期过滤；配股显式拒绝；已有真实事件重放 |
| tick/实时 | 历史不调用 current；五档、DF/records、缺盘口拒绝、先去重复后 count、过期/未来时间拒绝、当日涨跌停 |
| 共享停牌契约 | 000929 整日停牌日/分钟；513100 盘中暂停；skip/fill 全组合与 count200，共 19 项 |
| 错误及独立性 | 无效量价、重复/错证券/错时间、缺因子、SDK 超时、非法数据字段；禁止聚宽运行依赖和旧双来源配置 |

合成市场测试的预期由固定算例手算，证明适配算法；不冒充供应商在线一致性。
`gm_pause_20261008.json` 仅保存公开历史证券行情、交易日历和证券元信息，
真实快照重放复用 `tests/price_pause_contract.py` 的固定标准，不修改暂停价格、数量或时间轴。

## 本轮修复

1. 整日停牌且 `fill_paused=False` 返回全空值行，空分钟线保持浮点 dtype，避免金额转换异常。
2. `history_n` 条数查询拒绝未来 bar。
3. 历史零成交分钟补齐：GM 当日 179 根分钟线与日线量额完全守恒后，才能把缺口判定为零成交；价格仅向前沿用本源真实收盘。不能用复牌首价向过去倒填。
4. 上述日线闭合检查只允许已结束的历史日，且请求截止时间至少到收盘；历史盘中请求也不能读取稍后全天总量。量或额不守恒、缺少前收盘、数据不足均失败。
5. 不支持的推送订阅/退订明确抛出 `NotImplementedError`，避免继承基础接口的静默成功。

## 能力边界

基础接口清单通过反射与支持/未实现清单核对，新增基础接口时测试会提醒补充能力分类。
以下测试通过表示明确拒绝，不代表功能实现：extras、财务及连续财务、指数权重、行业、概念、基金信息、两融列表、期货接口、龙虎榜、限售股、get_trade_day、推送订阅/退订。

历史证券名称不保证时点还原；分红事件 Finance RPC 比较仍受基准服务限制，不能把行情除权窗口通过代替事件表验收。
当日稀疏分钟缺口尚无可靠完整日线证据时仍拒绝，不把历史日闭合方案用于盘中补值。

## 复现

```bash
# 项目开发依赖已安装；不需要构建 wheel/sdist。
python -m pytest -q -m 'not requires_network' $(cat tests/gm_regression_files.txt)

# 只运行此次补齐矩阵与实际 GM 历史市场快照，无须凭据。
python -m pytest -q tests/unit/test_gm_provider_contract.py tests/unit/test_gm_pause_saved.py

# 已有安全配置的 Windows SDK 环境可直接重跑共享在线契约。
python -m pytest -q -m requires_network tests/unit/test_price_pause_contract_live.py --live-providers=gm
```
